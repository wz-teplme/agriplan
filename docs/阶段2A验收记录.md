# 阶段2A：模型候选协议验收

日期：2026-10-17。状态：代码与本地协议验收通过；真实供应商和专业效果未验证。

## 本次交付

- `app/model.py`：复用服务端JSON请求边界，增加严格CandidateProposal；上下文最多128000字符，候选响应最多20000字符，单次请求40秒，不跟随重定向。
- `app/research.py`：提交结果时模型实际生成摘要、阶段、选用审核措施及历史处理。模型调用在数据库作用域外；确认输入说明、措施原文、数量、金额、约束和R版本仍由服务器提供。
- 模型不能新增关键字段、引用未知或重复措施、引用其他历史、漏处理当前历史。无法通过协议时任务failed，保留已有工具轨迹。
- 待决项保留并limited。提交时重新评价当前来源，即使模型调用期间资料撤回也不能通过。
- 页面及Markdown导出显示规则/模型/旧版本身份，只列实际引用，保留结构化措施、历史决策、待决事项与评价摘要。

当前目录开放的是流程资料审核主张。该协议不授权模型生成新的农艺处方，摘要/阶段仍需SR语义复核。
