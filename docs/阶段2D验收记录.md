# 阶段2D：报告原件与提取候选验收

日期：2026-10-18。状态：本地原件、pH候选和SR确认闭环验收通过；自动OCR、其他检测字段和真实报告识别质量未验证。

## 交付

- `reports.py`保存职责内原件及SHA-256、大小、MIME、随机存储键和上传身份。原件在数据库同级source-files，不使用用户文件名拼接路径。只允许UTF-8 txt/md、PDF、PNG/JPEG，最大8MiB，扩展名、类型和签名检查；下载、提取和确认核对原件完整性。FR只读，SR负责写入。
- 上传和提取分开。文本匹配、PDF文本层提取或人工转录都保存为未确认候选，带原值/原单位、规范值/单位、地块、采样日期、页码、行/表定位、摘录和身份。提取信号不是专业可信度，也不自动写事实。
- pypdf在独立进程解析文本层PDF，30页/100000字/15秒限制，单解压流限制2000000字节。扫描件、图片、加密/失败或超限报告保留原件转人工。明确不宣称自动OCR；pypdf文本提取与OCR的区别见[官方说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。
- 单个、明确格式的pH才形成自动候选；多个或无法完整解析的带数值pH标签转人工。单位、地块名称/ID、日期及定位缺失或不符阻塞确认。采样年份与本季不同提示SR核实，不自行声明专业有效期。
- SR明确核对后，仅写soil_ph和新事实R，同事务保存来源与审计。重复相同确认不新增R；过期R/报告/候选、越权或原件损坏拒绝。报告确认后不可改写，新原件需新上传。
- 未改变pH数值的事实版本继承来源（6.5→6.50也继承），数值变化清除关联。研究固定report_refs；质量规则candidate-review-v4重查报告/原件及版本关联，讨论只读该固定的已确认来源。检测报告不自动成为支持农艺处方的审核资料。
- v5三表：reports、report_extractions、fact_report_sources。旧数据增量迁移，旧C/P不重写。迟到报告只更新当前R，旧研究过期，需要基于新R重新研制；局部恢复属于2E。
- 页面有原件下载、候选/阻塞项、按页文本和提取历史、人工修正、独立确认，以及研究固定来源。表单绑定报告/候选/本季修订；迟到响应不污染其他对象。
