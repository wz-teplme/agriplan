# Research 2B Implementation Plan

> **For agentic workers:** Use executing-plans in the current session, with independent UI work and a final read-only review.

**Goal:** 支持不同类型事实的持久补问、一次恢复和多产品合作金额核算。

**Architecture:** 原Facts/计算保持主产品兼容，新增追加行；question_contexts扩展元数据。原事务/Worker/质量评价控制恢复与确认。

**Tech Stack:** 已有Python/Pydantic/SQLite/unittest及原生网页，不增加依赖。

**Spec:** docs/superpowers/specs/2026-10-17-research-2b-design.md。

## Global Constraints

- 不按历史或预算倒推专业用量；非必填仅按本次显式需要补问。
- 专业用量有来源，金额由Decimal核算。旧C/P不重写。
- 部分回答保持等待，最后回答与作业登记同事务。重复请求不得重复恢复。
- 当前目录版本、输入R、租约、依据与权限仍由服务器检查。
