# Research 2D Implementation Plan

> **For agentic workers:** Use executing-plans in this session; independent UI and final read-only review may use subagents.

**Goal:** 原件和候选分开保存，经SR核对后进入新事实R并保留来源。

**Architecture:** reports.py处理存储/候选/确认，report_extract.py隔离PDF解析；v5三表复用事实版本。主研究只保存已确认report_refs。

**Tech Stack:** 已有FastAPI/SQLite/Pydantic/原生JS，新增pypdf用于文本层PDF提取。

**Spec:** docs/superpowers/specs/2026-10-17-research-2d-design.md。

## Global Constraints

- 原件最大8MiB、随机存储键、哈希核验、职责检查；JSON仍64KiB。
- 候选绝不自动写事实；SR确认才写pH与新R，原C/P不改。
- PDF最多30页/100000字/15秒，图像或失败保留原件转人工；不冒充OCR。
- 原单位、地块、日期、页码/定位和候选身份必须保留。

```python
r=client.post('/api/seasons/s1/reports?filename=soil.txt',content='地块: 东河一号田\n采样日期: 2026-10-10\npH: 6.5 pH'.encode(),headers={'Content-Type':'text/plain'})

x=client.post('/api/reports/'+r.json()['id']+'/extract',json={'expected_revision':1})

report=x.json()
confirmed=client.post('/api/reports/'+report['id']+'/confirm',json={'expected_revision':report['revision'],'expected_input_revision':1,'extraction_id':report['current_extraction']['id'],'source':'SR核对原件'})
assert confirmed.json()['input_revision']==2
```
